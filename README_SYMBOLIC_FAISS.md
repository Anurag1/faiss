# 🧠 Symbolic FAISS Extension (CPU)

## Overview
This module adds deterministic symbolic reasoning and harmony optimization to FAISS CPU-based similarity search.

## Modules
- **GeometryHarmonizer** — deterministic centroid equilibrium.
- **CombinatorialQuantizer** — symbolic product quantization.
- **HarmonySearch** — symbolic re-ranking for balanced recall.
- **CoordinationBus** — symbolic multi-shard balancing.

## Example
```bash
python -m examples.symbolic_faiss_demo
```

Expected output:
```
[HARMONIZER] Generated 8 centroids with harmonic mean correction.
[QUANTIZER] Quantized 1000 vectors with symbolic combinatorial mapping.
[HARMONY SEARCH] Re-ranked results using symbolic equilibrium balancing.
[COORDINATION BUS] Balancing workloads across 3 shards.
```

## Requirements
```
pip install faiss-cpu numpy
```
